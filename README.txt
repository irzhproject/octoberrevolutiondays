Сайт-лонгрид — версия с обновлёнными формулировками текста.

Внешний вид, структура, сетка и стили не менялись: заменена только внутренняя текстовая часть.

Шрифты не включены в архив. Чтобы внешний вид остался прежним, положите свои файлы в assets/fonts/:
- FarabeeBlack.ttf
- GilroySemibold.ttf

Открытие: распаковать архив и открыть index.html в браузере.
